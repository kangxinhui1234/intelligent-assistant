## 1. 公司概况

### 1.1 公司简介

中国平安保险（集团）股份有限公司（股票代码：601318.SH / 2318.HK）是中国领先的综合金融服务集团，也是全球市值最大的保险公司之一。公司成立于1988年，总部位于深圳，已发展成为融保险、银行、投资三大主营业务为一体、核心金融与互联网金融业务并行发展的个人综合金融生活服务集团。

### 1.2 业务架构

| 业务板块 | 核心子公司 | 主要业务 |
|----------|-----------|----------|
| **寿险及健康险** | 平安人寿、平安健康险 | 个人寿险、健康险、年金 |
| **财产保险** | 平安产险 | 车险、责任险、意外险 |
| **银行业务** | 平安银行 | 零售银行、公司银行 |
| **资产管理** | 平安信托、平安证券、平安基金 | 信托、证券、基金 |
| **科技业务** | 金融壹账通、平安好医生、汽车之家 | 金融科技、医疗健康 |

### 1.3 核心竞争优势

- **"综合金融 + 医疗养老"双轮驱动：** 独特的商业模式形成强大的网络效应，个人客户数超 **2.44亿**，客均合同数2.97个。
- **科技赋能：** 拥有超 **5.7万项** 专利，AI坐席服务占比达86%，数字化运营效率行业领先。
- **品牌价值：** 连续多年蝉联全球最有价值保险品牌。
